# ЛР3: проверка восстановления данных

08.10.2026 восстановление проверено на отдельной демонстрационной PostgreSQL 18.
Версии сервера и клиентских `pg_dump`/`pg_restore` совпадали. Рабочая и тестовая
базы проекта не изменялись.

1. Применены миграции `001`–`004` к пустой демонстрационной базе.
2. Добавлено состязание «Проверка восстановления» с призовым фондом 250000 ₽.
3. Командой
   `make backup DATABASE_URL="$DEMO_DATABASE_URL" BACKUP_FILE=/tmp/horse-lab3-task12.dump`
   создана резервная копия.
4. Запись намеренно удалена; запрос `SELECT count(*) FROM competitions`
   вернул `0`.
5. Командой
   `CONFIRM_RESTORE=YES RESTORE_DATABASE_URL="$DEMO_DATABASE_URL" make restore BACKUP_FILE=/tmp/horse-lab3-task12.dump`
   база восстановлена.
6. Повторный запрос вернул «Проверка восстановления» и `250000`; история
   миграций содержит `001,002,003,004`.

Для повторения используйте отдельную базу и укажите её адрес в
`DEMO_DATABASE_URL`. Восстановление заменяет данные выбранной базы данными
архива; не указывайте в этой демонстрации рабочую базу проекта.
