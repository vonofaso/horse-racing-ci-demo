# Описание HTTP API

## Общая информация

Приложение предоставляет HTTP API для учёта владельцев, лошадей, жокеев, состязаний и результатов скачек.

После локального запуска базовый адрес:

```text
http://127.0.0.1:8000
```

Интерактивный интерфейс находится по адресу:

```text
http://127.0.0.1:8000/docs
```

## Системные адреса

| Метод | Адрес | Назначение | Успешный код |
|---|---|---|---|
| `GET` | `/` | Веб-интерфейс приложения | `200` |
| `GET` | `/api/system` | Информация о приложении и PostgreSQL | `200` |
| `GET` | `/health` | Проверка приложения и соединения с БД | `200` |
| `GET` | `/docs` | Интерактивная документация | `200` |

## Владельцы

| Метод | Адрес | Назначение | Успешный код |
|---|---|---|---|
| `POST` | `/owners` | Создать владельца | `201` |
| `GET` | `/owners` | Получить всех владельцев | `200` |
| `GET` | `/owners/{id}` | Получить владельца | `200` |
| `PUT` | `/owners/{id}` | Полностью изменить владельца | `200` |
| `DELETE` | `/owners/{id}` | Удалить владельца | `204` |

Поля запроса `POST` и `PUT`:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `name` | строка | да | Имя человека или название организации |
| `contact` | строка или `null` | нет | Телефон, почта или другой контакт |

Пример создания:

```json
{
  "name": "Jockey",
  "contact": "jockey@jockey.com"
}
```

## Лошади

| Метод | Адрес | Назначение | Успешный код |
|---|---|---|---|
| `POST` | `/horses` | Создать лошадь | `201` |
| `GET` | `/horses` | Получить всех лошадей | `200` |
| `GET` | `/horses/{id}` | Получить лошадь | `200` |
| `PUT` | `/horses/{id}` | Полностью изменить лошадь | `200` |
| `GET` | `/horses?name={часть клички}` | Найти лошадей по части клички без учёта регистра | `200` |
| `DELETE` | `/horses/{id}` | Удалить лошадь | `204` |

Поля запроса `POST` и `PUT`:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `name` | строка | да | Кличка |
| `birth_date` | дата `YYYY-MM-DD` | да | Дата рождения, не из будущего |
| `breed` | строка | да | Порода |
| `owner_id` | целое число | да | Идентификатор существующего владельца |

Пример создания:

```json
{
  "name": "Граф",
  "birth_date": "2020-05-10",
  "breed": "Орловский рысак",
  "owner_id": 1
}
```

|---|---|---|---|

## Результаты

| Метод | Адрес | Назначение | Успешный код |
|---|---|---|---|
| `POST` | `/results` | Создать результат | `201` |
| `GET` | `/results` | Получить все результаты | `200` |
| `GET` | `/results?competition_id={id}` | Результаты одного состязания | `200` |
| `GET` | `/results/{id}` | Получить результат | `200` |
| `PUT` | `/results/{id}` | Полностью изменить результат | `200` |
| `DELETE` | `/results/{id}` | Удалить результат | `204` |

Поля запроса `POST` и `PUT`:

| Поле | Тип | Обязательное | Описание |
|---|---|---|---|
| `competition_id` | целое число | да | Идентификатор состязания |
| `horse_id` | целое число | да | Идентификатор лошади |
| `jockey_id` | целое число | да | Идентификатор жокея |
| `position` | целое число | да | Положительное итоговое место |
| `time_seconds` | число | да | Положительное время в секундах |
| `disqualified` | логическое | нет | По умолчанию `false` |
| `disqualification_reason` | строка или `null` | нет | Обязательна при дисквалификации |

Пример создания:

```json
{
  "competition_id": 1,
  "horse_id": 1,
  "jockey_id": 1,
  "position": 1,
  "time_seconds": 94.2,
  "disqualified": false,
  "disqualification_reason": null
}
```

## Ошибки

| Код | Значение |
|---|---|
| `404` | Сущность или адрес не найден |
| `409` | Нарушено предметное правило или запись используется |
| `422` | Поля отсутствуют либо имеют неверные значения |
| `503` | PostgreSQL недоступна или не прошла проверку работоспособности |

Пример ответа:

```json
{
  "error": {
    "code": "not_found",
    "message": "Владелец с идентификатором 99 не найден(а)"
  }
}
```
